# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Stack

Tauri, React, TypeScript, Python, SQLite and FFmpeg; macOS first, Windows later.

## Users and purpose

DJs prepare local music for rekordbox: inspect tracks, review cue points, and export a playlist. Local work must function offline.

## Constraints

Preserve original audio, keep human edits, show real analysis and source provenance, and never imply an export was imported into rekordbox. This is not a performance DJ engine.

## Accessibility

Keyboard access, visible focus, labeled controls and readable light and dark themes are required.
