# CrateLoom

A local-first DJ preparation application. This repository is an early development prototype, not a release: see [docs/PROGRESS.md](docs/PROGRESS.md) for the precise feature and verification boundaries.

## Development on macOS

Requirements: Node.js 22+, npm, Rust, Python 3, and `ffmpeg` and `ffprobe` on PATH. The current engine uses only Python's standard library. Run from the repository root:

```sh
mkdir -p "$HOME/Library/Caches/CrateLoom/source"
rsync -a --exclude='._*' --exclude=.git --exclude=node_modules --exclude=target --exclude=dist ./ "$HOME/Library/Caches/CrateLoom/source/"
cd "$HOME/Library/Caches/CrateLoom/source"
npm ci
export CARGO_TARGET_DIR="$HOME/Library/Caches/CrateLoom/target"
export COPYFILE_DISABLE=1
cd apps/desktop
../../node_modules/.bin/tauri dev
```

The native-storage copy avoids AppleDouble `._*` files generated by shared drives, which otherwise break Tauri capability parsing. Repeat the copy after source changes. A Python executable can be selected with `CRATELOOM_PYTHON`. For the experimental frozen engine, set `CRATELOOM_ENGINE_EXEC` to its full path instead. See [M0 verification](docs/M0_VERIFICATION.md) for results and a hands-on checklist. The engine stores data in `~/.crateloom`; set `CRATELOOM_DATA` to isolate a test library. Original audio is referenced, not copied or modified. A development build needs the source tree and installed Python and FFmpeg; it is not a distributable app.

```sh
npm run build
python3 -m unittest discover -s engine/tests -v
CARGO_TARGET_DIR="$HOME/Library/Caches/CrateLoom/target" COPYFILE_DISABLE=1 cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml
```

## Export

Select a track, open Edit Cues, and choose Export XML. CrateLoom writes XML referencing the original audio and a separate `.crateloom.json` cue backup. Choose a new name if a backup already exists. In rekordbox, select the XML in Preferences > Advanced > Database (the exact label can vary by version), enable the rekordbox XML source in the browser, then locate and import the playlist. Check cues and timing yourself. XML creation has been tested; actual rekordbox import and alignment have not. No beat grid is exported.
