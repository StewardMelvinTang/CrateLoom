# Development architecture

React calls a restricted Tauri command. Rust holds one Python process and sends protocol-v1 JSON lines over stdin/stdout. Each message carries a request ID and params; responses carry the same ID and either a result or structured error. Stdout is reserved for the protocol. The Python engine alone writes the SQLite database, currently schema version 2. Tauri's asset scope is expanded only for imported track paths returned by the engine. The webview media element handles playback. FFprobe supplies metadata and FFmpeg decodes waveform data. A whole-file SHA-256 detects file changes; an FFmpeg audio-stream SHA-256 plus codec, sample rate and duration is used to recognize compatible tag-only changes. Legacy records receive a stream baseline when the unchanged original is next opened. This signature is not an acoustic fingerprint. The current implementation is deliberately incomplete; see PROGRESS.md before extending it.
